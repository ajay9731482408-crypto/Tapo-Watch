Connect to your Tapo Watch

Type the address of the computer that runs Tapo Watch. It is shown when you start it.

Away from home? Use the Tailscale address of that computer.

Install as an app

  1. Android (Chrome): tap the menu, then Install app.
  2. iPhone (Safari): tap Share, then Add to Home Screen.
  3. Computer (Chrome or Edge): click the install icon in the address bar.

How it works

The cameras, recordings and face detection run on your own computer. This page is only a doorway that remembers where it is, so your video never passes through this website.

Your address is saved on this device only.
